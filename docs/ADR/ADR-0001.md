# ADR 0001 — Target Model

## Decision

MiniRT v0.1 implements the architecture used by
Qwen/Qwen2.5-0.5B.

Architecture: Qwen2ForCausalLM.

## Model dimensions

vocab_size = 151936
hidden_size = 896
intermediate_size = 4864
num_layers = 24

num_query_heads = 14
num_kv_heads = 2
head_dim = 64

## Attention

- causal self-attention
- GQA
- 7 query heads per KV head
- RoPE
- attention scale = 1 / sqrt(64)

## Normalization

- pre-norm RMSNorm
- epsilon = 1e-6
- one RMSNorm before attention
- one RMSNorm before MLP

## MLP

SiLU(gate_proj(x)) * up_proj(x)
→ down_proj

## Projection shapes

q_proj:    [896, 896]
k_proj:    [128, 896]
v_proj:    [128, 896]
o_proj:    [896, 896]

gate_proj: [4864, 896]
up_proj:   [4864, 896]
down_proj: [896, 4864]

## Position encoding

rope_theta = 1_000_000
max_position_embeddings = 32768
sliding window disabled

## Output

Final RMSNorm followed by LM head.

Input/output embeddings are tied.
