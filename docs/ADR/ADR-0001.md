# ADR 0001 — Target Model and Reference

## Status

Accepted.

## Decision

MiniRT v0.1 implements `Qwen2ForCausalLM` semantics for Qwen2.5-0.5B.
The architecture is pinned to checkpoint revision
`060db6499f32faf8b98477b0a26969ef7d8b9987` and the
[published config](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/config.json).
The independent reference is the eager Qwen2 implementation in
[Transformers v4.40.1](https://github.com/huggingface/transformers/blob/v4.40.1/src/transformers/models/qwen2/modeling_qwen2.py).

Full checkpoint loading is optional for v0.1. Mandatory model tests use synthetic
weights and TinyModel, with separate target-shape operator and block fixtures.

## Dimensions

| Parameter | Qwen2.5-0.5B | TinyModel |
|---|---:|---:|
| Vocabulary | 151936 | 512 |
| Hidden size | 896 | 256 |
| Intermediate size | 4864 | 768 |
| Decoder layers | 24 | 2 |
| Query heads | 14 | 4 |
| KV heads | 2 | 2 |
| Head dimension | 64 | 64 |
| Maximum positions | 32768 | 256 |
| BOS token ID | 151643 | 1 |
| EOS token ID | 151643 | 2 |

TinyModel uses token ID `0` as fixture padding, masked out of attention and valid
sequence lengths. No padding ID is inferred for the target from this table.
Runtime consumes token IDs; a tokenizer is not required for synthetic fixtures.

## Decoder semantics

Each block applies pre-norm RMSNorm, causal GQA attention with output projection
and residual addition, then pre-norm RMSNorm, SwiGLU MLP and residual addition.
RMSNorm epsilon is `1e-6`. MLP activation is
`SiLU(gate_proj(x)) * up_proj(x)`, followed by `down_proj`.

The Q/K/V linear projections have biases; the output projection, all three MLP
projections and LM head have no bias. Bias is applied before RoPE. Weights use
`[out_features, in_features]`; a present bias has shape `[out_features]`.

| Projection | Target weight shape | Bias |
|---|---|---|
| Q | `[896, 896]` | `[896]` |
| K, V (each) | `[128, 896]` | `[128]` |
| Attention output | `[896, 896]` | None |
| Gate, up (each) | `[4864, 896]` | None |
| Down | `[896, 4864]` | None |

Attention uses scale `1 / sqrt(64)`, zero dropout and no sliding window.
Query head `h` reads KV head `floor(h / (num_query_heads / num_kv_heads))`:
seven adjacent query heads per KV head in the target, two in TinyModel.
Final RMSNorm is followed by a bias-free LM head tied to input embeddings.
Greedy argmax breaks ties by choosing the smallest token ID; fixed greedy
fixtures also record the reference logit margin.

Upstream weight names use `model.embed_tokens.weight`,
`model.layers.{i}.self_attn.{q,k,v,o}_proj.weight`, the Q/K/V `.bias` tensors,
`model.layers.{i}.mlp.{gate,up,down}_proj.weight`,
`model.layers.{i}.{input_layernorm,post_attention_layernorm}.weight`, and
`model.norm.weight`. A separately serialized `lm_head.weight`, if present,
must agree with the tied embedding. The exporter validates required tensors,
shapes and aliases before any rename or layout conversion.

## RoPE and cache positions

RoPE applies to all 64 coordinates of Q and K, with `theta = 1_000_000`, no
scaling and half-split pairing. For `i = 0..31` and zero-based position `p`:

```text
angle = p * theta^(-2*i / 64)
y[i]    = x[i] * cos(angle) - x[i+32] * sin(angle)
y[i+32] = x[i+32] * cos(angle) + x[i] * sin(angle)
```

The cache stores post-RoPE K and unrotated V. A fresh prompt occupies positions
`0..prompt_length-1`; the first decode input uses position `prompt_length`.
Paged addresses do not change semantic positions. See [ADR-0005](ADR-0005.md)
for population, append and generation completion.

## Independent reference and fixtures

Pin `transformers==4.40.1` in the reference environment and construct its
`Qwen2ForCausalLM` directly from an explicit TinyModel config, in evaluation mode
with eager attention. Load identical deterministic synthetic tensors into
upstream, the local Python reference and MiniRT. Q/K/V biases must contain
nonzero values, so omitting bias cannot pass by construction.

Runtime weights are rounded to FP16 on export; the FP32 reference uses those
same rounded values promoted to FP32. Record seed, generator/config version,
dependency versions and tensor hashes. Preserve embedding/LM-head tying.
Compare intermediate tensors, logits, KV contents and repeated greedy steps;
the local Python reference must first agree with the pinned upstream.

TinyModel preserves decoder semantics while reducing memory and test cost.
It does not cover target GQA `14/2`, hidden size `896` or MLP size `4864`:
separate synthetic operator/block fixtures cover those dimensions without
downloading the checkpoint. Precision and tolerances are in
[ADR-0003](ADR-0003.md); the check matrix is in
[validation.md](../validation.md).
